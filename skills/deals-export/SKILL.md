# 실거래 CSV 내보내기 (`/deals-export`)

`$ARGUMENTS` 를 아래 규칙으로 해석해 **deal-locator MCP 의 `deals_export` 도구**를 호출하고,
생성된 CSV 경로와 모수 요약을 전한다. **기본이 역매칭(마스킹 지번 복원)이다** — DB·분석
파이프라인의 원천 데이터 용도이기 때문이다.

## 1) 인자 해석

- **연월(필수)** — `202607`, `2026-07`, `2026년 7월`, `7월`(연도 생략 시 올해) 전부
  `YYYYMM` 으로 정규화해 `year_month` 에 넘긴다. `202601-202606`, `1월~6월`, `상반기`
  같은 범위는 `year_month` + `year_month_to` 로. **범위는 최대 24개월** — 넘으면 나눠
  부르지 말고 사용자에게 기간을 좁혀달라고 안내한다.
- **구 이름** — `강남구`·`강남` 이 있으면 `gu='강남구'`(정식 명칭으로). 없으면 서울
  25개 구 전체(기본).
- **`원본`·`마스킹 그대로`·`빠르게`** 류 표현이 있으면 `match=false`(역매칭 없이 국토부
  원본 1파일, 수십 초). 그 외에는 **기본값(match=true) 그대로** 둔다.

예시:
- `/deals-export 202607` → `deals_export(year_month="202607")` — 서울 전역, 복원본
- `/deals-export 2026년 1월~6월 강남구` → `year_month="202601", year_month_to="202606", gu="강남구"`
- `/deals-export 202607 원본` → `match=false` — 마스킹 원본 그대로

## 2) 답변 규칙 (반드시 지킬 것)

1. **파일 경로를 맨 앞에 전한다.** 복원본(`path`)과 미복원본(`path_unmatched`) 둘 다.
   고정 폴더(`~/deal-locator-exports/`, 날짜 하위폴더 없음)라 재실행 시 같은 경로를
   덮어쓴다(멱등) — 파이프라인이 경로를 하드코딩해도 된다고 안내한다. utf-8-sig 라
   엑셀에서도 바로 열린다.
2. **파일 구성을 설명한다**:
   - **복원본**(`rows_matched`건) — 원본 마스킹 지번은 그대로 있고 `복원지번`·
     `대지위치_표제부`·`도로명대지위치_표제부`·`매칭단계`·`매칭신뢰도` 컬럼이 추가됨.
     `confidence_breakdown`(정확매칭/추정매칭 건수)을 전하고, **추정매칭은 동일 스펙
     인접 건물일 가능성이 있으니 하류에서 `매칭신뢰도` 컬럼으로 필터 가능**함을 밝힌다.
   - **미복원본**(`rows_unmatched`건) — 지번 특정 실패(`역매칭실패사유` 컬럼 포함).
     **금액·면적은 실측값이므로 버리지 말라**고 안내한다. 0건이면 파일이 없다(정상).
3. **모수를 함께 전한다** — `rows_total` · `jiphap_excluded`(집합 제외) ·
   `cancelled_count`(해제신고 — **행은 남아 있고 '해제사유발생일' 컬럼으로 구분**,
   시세 분석 전 해제 행 제외를 권한다).
4. **이 CSV 는 통건물(유형='일반')만 담는다.** 집합(구분상가)은 취급 범위 밖(v1) —
   구분상가 데이터를 기대한 요청이면 그 사실을 밝히고 답을 지어내지 않는다.
5. **시간 안내** — 서울 전역 역매칭은 동별 건축물대장 수신 때문에 **콜드 캐시에서
   수 분~수십 분** 걸린다(한 번 받으면 이후 수 분). 큰 범위 요청은 시작 전에 이를
   알리고, 빨리 원본만 필요하면 `원본` 옵션을 안내한다.
6. **`status` 가 OK 가 아니면 그대로 전달한다.** NOT_FOUND 는 데이터 부재(최근 월은
   신고기한 30일로 아직 공개 전일 수 있음) — 수치를 지어내지 않는다. PARSE_ERROR 는
   message 의 교정 방법을 안내한다.
7. 결과 끝에 도구가 준 `source`(출처 한 줄)를 유지한다.

## 3) 출력 형태

```
■ 실거래 CSV — 서울전역 202607 (통건물, 지번 복원)
복원본: ~/deal-locator-exports/실거래_통건물_서울전역_202607_복원.csv — 171건 (정확매칭 139 · 추정매칭 32)
미복원본: ~/deal-locator-exports/실거래_통건물_서울전역_202607_미복원.csv — 31건 (금액·면적은 실측, 지번만 미확정)
전체 202건 · 집합(구분상가) 588건 제외(취급 범위 밖) · 해제신고 8건 포함(컬럼으로 구분)
※ 추정매칭 행은 '매칭신뢰도' 컬럼으로 필터 가능 · 재실행 시 같은 경로 덮어쓰기(멱등)
출처: 국토교통부 실거래가 공개시스템 · 건축HUB (공공데이터포털 data.go.kr)
```
