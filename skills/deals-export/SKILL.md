# 실거래 CSV 내보내기 (`/deals-export`)

`$ARGUMENTS` 를 아래 규칙으로 해석해 **deal-locator MCP 의 `deals_export` 도구**를 호출하고,
생성된 CSV 경로와 모수 요약을 전한다.

## 1) 인자 해석

- **연월(필수)** — `202607`, `2026-07`, `2026년 7월`, `7월`(연도 생략 시 올해) 전부
  `YYYYMM` 으로 정규화해 `year_month` 에 넘긴다. `202601-202606`, `1월~6월`, `상반기`
  같은 범위는 `year_month` + `year_month_to` 로. **범위는 최대 24개월** — 넘으면 나눠
  부르지 말고 사용자에게 기간을 좁혀달라고 안내한다.
- **구 이름** — `강남구`·`강남` 이 있으면 `gu='강남구'`(정식 명칭으로). 없으면 서울
  25개 구 전체(기본).
- **`역매칭`·`지번복원`·`주소포함`** 류 표현이 있으면 `match=true`. **기본은 false** —
  역매칭은 동별 건축물대장 수신 때문에 콜드 캐시에서 수 분~수십 분 걸린다.
  사용자가 명시하지 않았으면 켜지 말고, 원본을 먼저 준 뒤 "마스킹 지번을 복원한
  버전도 만들 수 있다(시간이 걸릴 수 있음)"고 안내만 한다.

예시:
- `/deals-export 202607` → `deals_export(year_month="202607")` — 서울 전역 1개월
- `/deals-export 2026년 1월~6월 강남구` → `year_month="202601", year_month_to="202606", gu="강남구"`
- `/deals-export 202607 역매칭` → `match=true`

## 2) 답변 규칙 (반드시 지킬 것)

1. **파일 경로를 맨 앞에 전한다.** `path` 를 그대로 보여주고, 인코딩이 utf-8-sig 라
   엑셀에서 바로 열린다는 점을 덧붙인다.
2. **모수를 함께 전한다** — `rows`(통건물 행수) · `jiphap_excluded`(집합 제외) ·
   `cancelled_count`(해제신고 — **행은 CSV 에 남아 있고 '해제사유발생일' 컬럼으로
   구분된다**는 점을 반드시 밝힌다. 시세 분석 전 해제 행 제외를 권한다).
3. **이 CSV 는 통건물(유형='일반')만 담는다.** 집합(구분상가)은 취급 범위 밖(v1)이라
   빠져 있다 — 구분상가 데이터를 기대한 요청이면 그 사실을 밝히고 답을 지어내지 않는다.
4. **마스킹 안내** — `masked_count` 를 전하고, `match=false` 였으면 "지번이 `6**` 처럼
   마스킹된 원본"임을 밝힌다. `match=true` 였으면 `matched_count` 와 함께 "복원 지번은
   '대지위치_표제부'·'매칭단계' 컬럼, 추정매칭은 동일 스펙 인접 건물일 가능성 있음"을
   고지한다.
5. **`status` 가 OK 가 아니면 그대로 전달한다.** NOT_FOUND 는 데이터 부재(최근 월은
   신고 지연으로 공개 전일 수 있음 — 실거래 신고기한 30일을 언급) — 수치를 지어내지
   않는다. PARSE_ERROR 는 message 의 교정 방법을 안내한다.
6. **큰 범위 요청은 시간 안내** — 전역×다개월 콜드 캐시는 구·월당 API 1회씩이라
   수 분 걸릴 수 있다. 진행 중임을 먼저 알린다.
7. 결과 끝에 도구가 준 `source`(출처 한 줄)를 유지한다.

## 3) 출력 형태

```
■ 실거래 CSV — 서울전역 202607 (통건물)
파일: ~/deal-locator-exports/2026-08-17/실거래_통건물_서울전역_202607.csv (utf-8-sig, 엑셀 호환)
행수: 231건 · 집합(구분상가) 1,024건 제외(취급 범위 밖) · 해제신고 12건 포함(컬럼으로 구분)
지번 마스킹 219건 — 원본 그대로(복원본이 필요하면 '역매칭'을 붙여 다시 요청)
출처: 국토교통부 실거래가 공개시스템 · 건축HUB (공공데이터포털 data.go.kr)
```
